- Fisher discovery scans live object regions first only to collect active FishingSet objects; slot mapping is read-only RodRestController consensus.
- Partial rig rescans now run every second instead of every 8 seconds while the mapping is incomplete.
- When one RodRestController is temporarily missing, two measured RodRest controllers plus the three valid live FishingSet roots keep all U1/U2/U3 rods visible instead of degrading to one rod/no rod.
- FishingSet validation now stores the root Rig class address, so snapshot validation does not invalidate newly found Fisher rigs.
- Forced refresh really rescans when a previously complete mapping points at rebuilt Unity objects.
- Live bite display now shows fish name first when species is readable, uses -- for unknown live weight, and marks level as 待确认 until weight/rarity/grade is observed.
